# MVP Scope and Non-Goals

## In scope
- Detect time-sensitive claims in LLM responses
- Support pricing, software/API versions, and company leadership only
- Retrieve live evidence using Tavily
- Return Supported, Contradicted, or Unclear verdicts
- Include per-claim evidence and freshness timestamps
- Define cache freshness metadata and validate Bifrost cache-hit feasibility
- Provide a basic dashboard and manual verification workflow
- Evaluate extraction, verdict quality, latency, and cost

## Out of scope for MVP
- General fact-checking across arbitrary topics
- Legal, medical, financial, or safety-critical verification
- Autonomous browsing or actions
- Claims that cache invalidation works before Bifrost behavior is proven
- Fabricated analytics, demo evidence, or fake integration status
